# PLUTON CODE ♠ — листа за довршување и статус на серверот

Ова е главниот контролен документ за ZLATKO AI MODE / PLUTON CODE. Ги раздвојува завршените работи од проверките и работите што допрва треба да се изградат.

## 1. Дали PLUTON CODE е сервер?

**Не е потврдено дека постои целосно активен PLUTON backend сервер.**

| Дел | Потврден статус |
|---|---|
| Изворниот код на проектот | На GitHub, во `main` |
| GitHub Pages deployment | GitHub Actions deployment-проверка е завршена успешно; целосното однесување на објавената апликација треба да се тестира независно |
| Локално зачувување | Дел од податоците се зачувуваат во прелистувачот на уредот |
| Серверска база на податоци | Не е потврдена |
| Серверска автентикација и улоги | Не е потврдена; моменталните улоги на ПИКОВА ДАМА се локални |
| Активни AI API-и | Не се потврдени со реални повици |
| Реални 2,5 милиони работници на JOKER 2 | Не; тоа е планиран логички капацитет |
| Реални 100.000 Плутoни на ПИКОВА ДАМА | Не; тоа е планиран логички капацитет |

Линкови: [GitHub репозиториум](https://github.com/zlatkomarina0-ai/ZM-AL-MODE) · [Веб-апликација](https://zlatkomarina0-ai.github.io/ZM-AL-MODE/).

**Разликата:** GitHub го чува кодот, а GitHub Pages може да ја прикажува веб-апликацијата. Тоа само по себе не значи дека постои посебен сервер што работи постојано, чува заедничка база или извршува задачи во заднина.

## 3. Правило за статус

- **Кодирано:** кодот е додаден во репозиториумот.
- **Тестирано:** соодветните автоматизирани или рачни тестови поминале.
- **Објавено:** deployment-от е успешен.
- **Активно:** реалната инфраструктура работи и е тестирана со валиден сервис.
- **Планирано:** идеја или логички капацитет што сè уште не е реализиран како реална инфраструктура.

Планираните капацитети никогаш не се прикажуваат како активни ресурси.
